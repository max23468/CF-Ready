Why not use Address 2 for Codice Fiscale

Renaming an address field looks like a shortcut, but it changes the meaning of the data and may show customers two requests for the same information.

Updated 12 November 2026

Where the shortcut comes from

With standard settings, Shopify’s Codice Fiscale field is optional. The second address line, on the other hand, can be set as optional, required or hidden. That is why many stores renamed Address 2 (“Interno” in Italian checkouts) to “Codice Fiscale” and made it required: it was the quickest way to stop receiving orders without a code.

The shortcut problem

Address 2 belongs to the address. When it becomes Codice Fiscale, the value still sits in a field built for another purpose. If Shopify also shows its native tax field, the customer may see two similar boxes without knowing which one to complete. Some type the code twice, others fill in only one field, others enter their flat number where you expect the Codice Fiscale.

Four hidden costs

  • Ambiguity: staff, integrations and customers no longer share one meaning for the field.
  • Misplaced data: the second line is part of the address, so the Codice Fiscale can end up on shipping documents and labels, while the flat or staircase number has nowhere to go.
  • Maintenance: custom labels and translations must remain aligned over time, in every checkout language.
  • Weak validation: an address field was not designed around Codice Fiscale rules. It also accepts RSSMRA85T10A562X, whose check character is wrong, or any random string.

What CF Ready does

CF Ready reads the Italian and English versions of the Address 2 label and compares them: if they appear to be used for Codice Fiscale, it flags a likely conflict. Shopify does not expose to the app whether the second line is optional, required or hidden, so the app asks you to declare it. After your confirmation it can restore the translations and overrides it manages; for the primary language text it shows guided steps.

The label does not tell the whole story.

Comparing the label does not prove who changed it and does not reveal how the field is set up. The warning does not block activation, and CF Ready never uses the second line to collect or validate Codice Fiscale.

A clean migration

  1. Check whether Address 2 was renamed in checkout, in every language you use.
  2. If you made it required only for Codice Fiscale, set it back to optional or hide it, depending on how you use addresses.
  3. Restore the address label, from the app for managed translations or with the guided steps.
  4. Configure the native Codice Fiscale field in CF Ready, optional first and then required if you need it.
  5. Test Italian and English checkout before making the rule required.
  6. Tell whoever prepares invoices: in older orders the code stays in the second line, in new ones it is in the tax field.

Orders already collected

The change applies to new checkouts. In orders already received, the code stays where the customer typed it, and CF Ready does not move it. The option that standardizes Codice Fiscale in uppercase applies only to the native tax field, not to the second address line.

No theme change

Cart and Checkout Validation runs in Shopify. It does not require a Liquid field, Theme App Extension or code that later has to be removed from the theme. If you uninstall one day, nothing is left behind in your theme.

Frequently asked questions

Does CF Ready check a Codice Fiscale typed into Address 2?

No. CF Ready does not use the second address line to collect or validate Codice Fiscale. It works only on Shopify’s native tax field.

Does the Address 2 warning stop me from activating the check?

No. The warning flags a likely conflict and asks you to confirm how the second line is set up, but it does not block activation. It is still worth resolving, because customers could see two requests for the same information.

What happens to orders already collected with Address 2?

They stay as they are: in those orders the Codice Fiscale remains in the second address line. CF Ready does not move it to the tax field. For a transition period, whoever prepares invoices needs to look in both places.

Can I change the Address 2 label myself?

Yes. After your confirmation, CF Ready can restore the label translations it manages. For the text in the checkout’s primary language, the app shows guided steps to follow in Shopify’s checkout text editor.
