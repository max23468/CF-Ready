Where to find the Codice Fiscale in a Shopify order

The Codice Fiscale in a Shopify order comes from the native field of the Italian checkout, where the customer enters it. After the purchase the value stays in the order, together with the PEC when it was filled in. Here is where to look for it, how to keep it consistent and what to do when it is missing.

Updated 12 November 2026

Where the Codice Fiscale appears after the purchase

Codice Fiscale and PEC are native tax fields of Shopify’s checkout, separate from the address. In its help page on checkout form options, Shopify explains that these additional fields are displayed after the payment details section and that, after an order is placed, you can find the customer’s additional information on the order details page.

To check the value, open the order in the Shopify admin. The data lives in the order: CF Ready does not copy it to its own servers and does not show it on a separate page in the app.

Exports, management tools and invoicing apps

The Codice Fiscale is part of the order data, so a tool that reads Shopify orders can receive it. That does not mean every export, management tool or invoicing app also reads the native tax fields: it depends on how the tool queries Shopify and which columns or fields it supports.

Before you rely on a workflow, complete a test order with a sample Codice Fiscale and check that the value reaches the final file or document. If it does not, ask the provider whether it supports Shopify’s Italian checkout tax fields. CF Ready does not issue or transmit invoices and does not connect to invoicing software.

Values written in different ways

Customers type their Codice Fiscale in different ways: all lowercase, mixed case, with a space at the start or end. During checkout CF Ready checks the Codice Fiscale format without changing it, so the order keeps what the customer typed. The same applies to PEC.

If you prefer consistent values, you can turn on “In orders, save the tax code in uppercase and the PEC in lowercase” on the app’s Checkout rules page. It works like this:

  • it stays off until you turn it on, and it only appears if you manage at least one of the two fields;
  • it asks for order access only when you turn it on; without that permission it stays off;
  • after each new order is created, it removes leading and trailing spaces and saves the Codice Fiscale in uppercase and the PEC in lowercase;
  • it only touches managed fields, optional or required, and only formally valid values: an invalid or already consistent value stays as it is;
  • it only works while the CF Ready Validation is active;
  • it does not overwrite changes you make to the order later.
Orders you already received.

When you save the option, CF Ready also fixes orders from the last 60 days, the period covered by order access. Older orders stay as they are.

CF Ready reads and rewrites the values in memory. It does not save them in its databases or logs and does not add tags or notes to the order.

When the Codice Fiscale is missing

An order can arrive without a Codice Fiscale for several reasons:

  • the field was unmanaged or optional and the customer left it empty;
  • the order was placed before the Validation was activated;
  • billing was outside Italy or every delivery was abroad, cases where the rules do not apply;
  • the order had no delivery country, Shopify did not show the field and the option for Codice Fiscale on orders without shipping was off;
  • checkout stayed open because of a technical error or because the trial or plan was not active.

There is also a Shopify case. Since 6 November 2026 the native field rejects 11-digit numeric codes and codes with omocodia before CF Ready checks them. If the field is optional, customers with one of these codes can only leave it empty.

In all these cases, ask the customer for the value through the process you use for invoicing, and decide with your accountant how to handle the order. CF Ready does not add a missing value to an order. For future orders you can make the field required, so customers enter it before confirmation.

Frequently asked questions

Does the Codice Fiscale appear on the Shopify order page?

Yes. According to Shopify’s help page on checkout form options, after an order is placed you can find the customer’s additional information on the order details page. A test order shows you how it appears in your store.

Does CF Ready store customers’ Codice Fiscale values?

No. Validation runs inside Shopify during checkout. If you turn on standardization in orders, CF Ready reads and rewrites Codice Fiscale and PEC in memory, without saving them in its databases, its logs or notes on the order.

Can I standardize the Codice Fiscale in orders I already received?

Yes, within the last 60 days, the period covered by order access. Older orders stay as they are, and an invalid value is never changed.

Can CF Ready add a missing Codice Fiscale to an order?

No. CF Ready only standardizes values that are already present and formally valid. For an order without a Codice Fiscale, ask the customer for it and decide with your accountant how to handle the order.
