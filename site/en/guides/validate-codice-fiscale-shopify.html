Formal Codice Fiscale validation on Shopify: how it works

Formal Codice Fiscale validation on Shopify takes more than counting sixteen characters. A serious check verifies that the code is built correctly without turning into an identity check.

Updated 14 November 2026

How a 16-character Codice Fiscale is built

An individual’s Codice Fiscale has sixteen characters, derived from surname, first name, date of birth and municipality of birth. That is why a code can look right and still be wrong: one mistyped letter or digit is enough.

Omocodia and 11-digit numeric codes

When two people would get the same code, the Italian Revenue Agency replaces some digits with letters: this is omocodia, and the code stays valid. Companies, public bodies and provisional codes have a numeric Codice Fiscale of 11 digits instead. CF Ready treats it as a Codice Fiscale: VAT numbers stay outside CF Ready. Today both forms run into the native field limit described below.

The limit of Shopify’s native Codice Fiscale field

Since 6 November 2026, the Codice Fiscale field, one of Shopify’s native Italian tax fields, applies its own check: it accepts only the ordinary 16-character structure and rejects numeric and omocodia Codice Fiscale codes before any app runs. CF Ready treats them as valid, but until Shopify fixes the field, customers with these codes cannot complete the order. In tests on the same day, the native check also accepted wrong codes that CF Ready recognises.

Formally valid does not mean it belongs to that person.

CF Ready does not query the Italian Revenue Agency and does not certify identity, existence or ownership. It reduces input errors before the order is completed.

Codice Fiscale checks at checkout with CF Ready

CF Ready checks Codice Fiscale at checkout and shows a message only when the merchant’s rule requires it, for example when you require Codice Fiscale at Shopify checkout. Codice Fiscale and PEC can each be set as optional or required, independently. The message, in Italian or English, tells the customer what to fix. CF Ready works on every Shopify plan, from Basic to Plus, without theme changes. CF Ready does not store Codice Fiscale values. You can try the cases you care about in the app’s simulator before activating the check.

Frequently asked questions

Does a formally valid Codice Fiscale necessarily belong to the customer?

No. Formal validation checks that the code is built correctly. It does not query the Italian Revenue Agency and cannot tell whether the code exists or belongs to the person entering it.

Why does Shopify reject an omocodia Codice Fiscale?

Since 6 November 2026, Shopify’s native field rejects omocodia and numeric codes before any app runs. CF Ready treats them as valid, but it cannot override Shopify’s rejection.

What does the customer see after a Codice Fiscale mistake?

They see the message chosen by the merchant, in Italian or English, with a short hint about what to fix.

Do I need Shopify Plus to validate Codice Fiscale at checkout?

No. CF Ready works on the Basic, Grow, Advanced and Plus plans, with no development and no theme changes.
